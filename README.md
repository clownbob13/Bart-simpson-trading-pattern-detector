# Bart Simpson Pattern Detector

A Pine Script indicator for TradingView that looks for the **Bart Simpson trading pattern** on price charts.

It highlights potential patterns and helps identify the main price move, consolidation, and reversal that make up the setup.

## Features

* Detects potential Bart Simpson patterns
* Highlights detected patterns on the chart
* Adjustable detection settings
* Works across different markets and timeframes
* Simple visual signals
* Built for TradingView using Pine Script

## How It Works

The indicator looks for a sharp price move followed by a period of relatively tight consolidation and then a move in the opposite direction.

Because market patterns aren't always identical, the indicator uses adjustable settings to control how strict the detection is.

## Usage

1. Open TradingView.
2. Add the Pine Script indicator to your chart.
3. Adjust the detection settings if needed.
4. Watch for highlighted patterns on the chart.
5. Use the detected structure as part of your own analysis.

## Disclaimer

This indicator is for educational and informational purposes only.

A detected pattern does not guarantee that price will move in a specific direction. The indicator can produce false signals, so always do your own research and use proper risk management.
